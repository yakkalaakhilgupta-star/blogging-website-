Sprint Overview
This plan takes The Verdant Page from its current Sprint 1 baseline to a fully self-sufficient, launch-ready platform in 10 working days. Each day has a clear focus and checkbox task list. The three phases are:

Phase	Days	Focus
Phase 1: Foundation	Days 1–3	Quick wins, legal pages, email infrastructure (Resend), double opt-in, DB backup
Phase 2: Core Features	Days 4–7	Full admin CMS (articles, species, portfolio), markdown editor, full-text search, Cmd+K, pagination
Phase 3: Polish & Launch	Days 8–10	Analytics dashboard, newsletter broadcast UI, bookmarking, SEO audit, Lighthouse, QA, release tag

	Rule:  Each day ends with a working, committed build. No feature is left half-done overnight.

Risks & Mitigations

Risk	Likelihood	Mitigation
Resend email API setup takes longer than expected	Medium	Use Resend sandbox for Day 2; real sending not needed until Day 3 double opt-in
Markdown editor library has styling conflicts with Tailwind	Low	@uiw/react-md-editor isolates its CSS; test in a sandbox component first
tsvector migration fails on large articles table	Low	Run migration in a transaction; add search_vector in a separate non-blocking ALTER
Day 10 Lighthouse score below 80	Medium	Defer bookmarking/vitals to post-sprint if needed; keep QA day clear for fixes
No buffer day if a feature slips	High	Keep Day 10 tasks light; if Day 9 slips, cut bookmarking (lowest-impact feature)

Definition of Done
The sprint is complete when ALL of the following are true:

•	Automated daily database backup is running and verified
•	Privacy Policy and Terms of Service pages are live
•	sitemap.xml and robots.txt are reachable
•	JSON-LD Article schema is present on all article pages
•	Welcome email and double opt-in confirmation email are sending via Resend
•	Admin can create, edit, and delete articles entirely through the UI
•	Admin can create, edit, and delete species and portfolio clips through the UI
•	Full-text search works on /articles and via Cmd+K overlay
•	Article list uses cursor-based pagination
•	Analytics dashboard shows page views and subscriber growth
•	Newsletter broadcast can be sent to all confirmed subscribers from the admin UI
•	Cookie consent banner is shown to first-time visitors
•	Lighthouse scores on key pages are 80+ on Performance, 90+ on SEO and Accessibility
•	All admin endpoints require Bearer token — verified with a direct curl test
